# Dortmund 2026 ⚫🟡

Weekendplanning voor Juup, Jelle & Tido — Dortmund, vrijdag 20 t/m zondag 22 november 2026.

🌐 **Live site:** [juuphietbrink.github.io/dortmund](https://juuphietbrink.github.io/dortmund/)

Statische website gehost via **GitHub Pages**, met een interactieve kaart (Leaflet + OpenStreetMap) van het Airbnb en alle locaties.

## Lokaal bekijken

Open simpelweg `index.html` in een browser, of start een lokale server:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## GitHub Pages

Elke push naar `main` wordt automatisch gepubliceerd (binnen ~1 minuut).

## Bestanden

- `index.html` — de pagina met programma, events, restaurants en bars
- `style.css` — styling (BVB-thema: zwart & geel)
- `script.js` — actieve nav + interactieve Leaflet-kaart
- `.nojekyll` — voorkomt Jekyll-processing op GitHub Pages
